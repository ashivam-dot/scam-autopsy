# Tools and assets

The original Python code and brand geometry in this repository are available under its MIT license. The rendered graphics are created from that original geometry and typography. No stock footage, copyrighted music, scraped video clips or third-party likeness is used in the initial release queue.

Kokoro-82M speech weights: [hexgrad/Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M), Apache-2.0, revision `f3ff3571791e39611d31c381e3a41a3af07b4987`, voice `af_heart`. The license and pinned revision were verified from the Hugging Face model metadata on 8 October 2026. Downloaded model weights are not committed.

FFmpeg, Pillow, PyTorch, Kokoro's Python runtime, DejaVu fonts and other dependencies retain their respective licenses. System packages are installed from the GitHub runner's Ubuntu distribution; Python package versions are pinned in `uv.lock`.

FTC and FBI pages are research sources. URLs and limited evidence passages accompany scripts; the narration and visual explanations are original. A citation does not grant rights to unrelated third-party assets that might appear on a source page. New content generated by an external model must continue to pass the source and editorial review checks.

The automated research refill uses the owner's existing **Google Gemini Developer API Free tier** project. It sends public FTC article text, source URLs, and draft script text to configured free-tier text models for writing and a different model's review. The configured reviewer can be a non-Lite Flash model or, when available, Gemma 4 through the same API; [Google's Gemma API guide](https://ai.google.dev/gemma/docs/core/gemma_on_gemini_api) documents hosted Gemma 4 access. Google's [Gemini Developer API pricing page](https://ai.google.dev/gemini-api/docs/pricing), checked on 9 October 2026, lists free input and output tokens for eligible Flash models and Gemma 4, with Gemma 4's paid tier marked unavailable. It also says Free-tier content may be used to improve Google's products. The workflow checks the live model catalog and limits each refill to four generation calls. No paid API billing was enabled for this project; free-tier limits, model access, and pricing can change.

Gemma 4 is an open-weight model with its own [official model license](https://ai.google.dev/gemma/apache_2) and API terms; its terms should be checked separately from the Kokoro speech model's license above. Gemma weights are not downloaded or committed by this studio, and Gemini API access does not guarantee a particular model will be available to this project.

The Gemini API key is supplied through a GitHub Actions secret. The key and raw model replies are not committed to the repository. Accepted, source-checked script text and bounded review metadata are committed so the publishing queue is reviewable; prompts use public source and script material, not commenter identities or private account data.
